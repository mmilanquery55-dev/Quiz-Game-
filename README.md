Project Overview

This project is a beginner-friendly Python application that simulates a quiz game. Users answer different general knowledge and programming-related questions. The system checks whether the answers are correct and keeps track of the score.

Features :-
Multiple quiz questions,
User input handling,
Score calculation,
Final result display,
Simple and easy-to-understand Python logic . 

Technologies Used :- 
Python ,
Lists ,
Dictionaries ,
Loops,
Conditional Statements ,
f-strings ,
Workflow of the Project :- 
Store quiz questions and answers in a list of dictionaries ,
Display questions one by one using a loop ,
Take user input for answers , 
Compare user answers with correct answers ,
Increase score for correct answers ,
Display the final score after quiz completion . 

Learning Outcomes :- 
By building this project, you can learn:
 
Python basics , 
Working with lists and dictionaries , 
Looping concepts , 
Conditional statements , 
User input handling , 
Simple game logic , 
Future Improvements , 
Add timer for questions , 
Add multiple difficulty levels , 
Store high scores ,
Add random question selection , 
Create GUI version using Tkinter , 
Add categories like Science, Sports, Programming, etc.
